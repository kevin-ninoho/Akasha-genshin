# Akasha visual assets

- `assets/archons/*.webp` — seven original AI-generated reinterpretations created with OpenAI image generation for the locally installed Akasha UI, depicting Venti, Zhongli, Raiden Ei, Nahida, Focalors, Mavuika, and the Tsaritsa with their associated elements. Genshin Impact characters and settings are HoYoverse intellectual property; these are fan-made visual interpretations, not official assets or an endorsement.
- The Archon wallpapers are selectable local UI backgrounds. They include no knowledge-base text, index, extracted portrait, or video content.
- Knowledge-base resources remain on the user's machine and are not copied into the application package.
